# 3B · 首页桌面（全屏地图 + 浮层）

- 日期：2026-10-23
- 范围：`/` 首页桌面；移动端只保留 3C 的入口结构，未做移动验收
- 账号：demo01（周末去哪儿 OWNER、校园美食地图 EDITOR）

## 改动

- `MapListView.vue`
  - 首页改为全屏地图：`loadAmap(mapRef, null, { controls: false })` + 地点标记控制器。
  - 左侧 300px 地图列表：搜索、角色 pill、成员/地点数、选中态（accent-tint + 左侧 2px 条）、底部唯一 primary「进入地图」+ 静音文字「用邀请码加入」。
  - 右侧摘要：≥1440 默认展开（296px）；1100–1439 默认折叠为「当前地图」胶囊，点开为 280×内容高度浮卡；769–1099 不渲染摘要，仅保留左列表。
  - 摘要动作只用文字按钮「进入地图」「复制邀请码」，不放大色块主按钮；邀请码只在地图详情返回 `inviteCode` 时显示（编辑者看不到，符合权限）。
  - 地图标记点击 → `/maps/{mapId}?place={placeId}`；右下缩放；左下地点数量提示；地点/详情加载失败各自降级。
  - 创建 / 创建后邀请码 / 邀请码加入三个弹窗统一 `.ui-dialog`，字段使用阶段 2 的 `.ui-input` / `.ui-textarea` / `.ui-btn`。
- `useAmap.js`
  - 新增 `preserveOtherOverlays`（默认 `false`，工作台/助手行为不变）；首页传 `true`，切换地图只移除本控制器创建的标记，不调用 `clearMap()`。
  - 标记内容改为真实 DOM（`createPlaceMarkerElement`），直接在内容上绑定 click 并 `stopPropagation`；移除原先不稳定的 `marker.on('click')`。
- `ui-v2.css`
  - 仅新增 `.home-*` 作用域样式；无新基础组件、无重写 Sheet。
  - 响应式状态以 `window.innerWidth` 为准，同时监听 `resize` 与三个 `matchMedia` 的 change，避免只依赖一种事件源。

## 布局实测

| 视口 | 左列表 | 右摘要 | 结果 |
|---|---|---|---|
| 1440×900 | 300×347 | 296×238（默认展开） | 双浮层；地图仍为最大区域 |
| 1280×800 | 300×347 | 默认折叠胶囊 228×38；点开 280×238 | 单 primary 在左列表 |
| 1100×800 | 300×347 | 折叠胶囊 228×38 | 单 primary 在左列表 |
| 1024×768 | 300×347 | 不渲染 | 单浮层 |
| ≤768 | — | — | 交给 3C 移动 Sheet |

- 1280：缩放控件 40×88 位于右下（x=1224, y=692），摘要与控件、左列表与控件均无相交。
- 地图容器在三档桌面均为 `viewport` 全尺寸；浮层覆盖率 13%–22%，满足地图主体要求。
- 选中行：accent-tint 背景 + 左侧 2px accent 短条；行尾 chevron 只在 hover/选中出现。

## 问题闭环

| 问题 | 处理 | 复核 |
|---|---|---|
| AMap 自定义 content 的 `marker.on('click')` 在部分环境不触发 | 改为 DOM 内容直接 click + 阻止冒泡 | 首页/工作台均可点开；深链到详情 |
| 切换地图 `clearMap()` 会清掉非本组件覆盖物 | 控制器新增 `preserveOtherOverlays`，仅首页启用 | 首页切换只重建地点标记 |
| 右摘要曾与左列表同为「大色块主按钮」 | 摘要改为纯文字动作，左列表保留唯一 primary | 1440/1280 截图 |
| 1100–1439 摘要占位过重 | 默认折叠为胶囊，点开 280×内容高度 | 1280/1100 截图与 DOM |
| 769–1099 出现第二浮层 | 该档不渲染摘要与胶囊 | 1024 截图 |
| 快速切换可能旧请求覆盖新选中 | 每次选择递增 `requestSeq`，地点/详情各自校验 | 2→1→2 实测 |
| 详情缺字段时摘要崩溃 | `members ?? []`、`inviteCode || ''`、`Number(...) || 0` | EDITOR 摘要正常 |
| 地图容器尺寸变化 | `ResizeObserver` 调 `map.resize()`；卸载 disconnect + `map.destroy()` | 代码复核；3F 回归 |

## 未验收 / 环境限制

- **空态、地图加载失败、地点/详情失败**：代码路径已实现（`EmptyState`、地图错误卡 + 重试、地点错误提示 + 重试、详情降级），但当前 demo 数据不触发，未做真实截图；留到 3F 用可控故障复验，不宣称已通过。
- **EP 弹窗关闭**：IAB 标签页 `document.visibilityState = "hidden"`，`requestAnimationFrame` 被暂停，Element Plus 的过渡钩子无法收尾，关闭后 DOM 停在 `dialog-fade-leave-active`（打开、遮罩、字段、按钮均正常）。这是截图环境限制，不是业务逻辑；需要真实可见 Chrome 复核关闭动画。
- **加入弹窗**：只做了 DOM 实测（标题/输入/按钮），未截图。
- 地图仍为 `amap://styles/fresh`，按用户决定维持现状。
