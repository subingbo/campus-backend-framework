# 3A · 沉浸壳层与移动导航

- 日期：2026-10-23
- 范围：只改壳层；首页/助手页面内容仍为旧结构，3B/3D 才替换
- 账号：demo01

## 改动

- `router/index.js`：`/` 与 `/assistant` 增加 `meta: { immersive: true, mobileNav: true }`。
- `AppShell.vue`：
  - 桌面 immersive：左右悬浮胶囊顶栏（沿用阶段 2）。
  - ≤768 mobileNav：保留 56px 静态导航栏，避免沉浸页失去导航/账号出口。
  - ≤600：导航只显示线性图标，隐藏文字。
  - ≤389：品牌只保留图标。
  - 导航项补 `AppIcon`（地图/消息/日程/AI），未读胶囊保留。
- 工作台 `/maps/:id` 仍隐藏移动端全局顶栏，使用工作台自己的胶囊。

## 实测

| 宽度 | 首页 docScroll | 助手 docScroll | 顶栏高度 | 结论 |
|---|---|---|---|---|
| 1440 | 1440 | 1440 | 52 | 无横滚 |
| 1280 | 1280 | 1280 | 52 | 无横滚 |
| 1024 | 1024 | 1024 | 52 | 无横滚 |
| 390 | 390 | 390 | 56 | 无横滚 |
| 375 | 375 | 375 | 56 | 无横滚 |

375 细项：品牌 26px、导航 `clientWidth = scrollWidth = 256`、账号 35px；导航文字全部隐藏，无溢出。
