# 3D · AI 助手桌面（地图全屏 + 悬浮聊天）

- 日期：2026-10-23
- 范围：`/assistant` 桌面 1440/1280/1024；移动只保留 3E 的临时底部面板
- 账号：demo01；会话 chat=197（真实历史规划）

## 改动

- `AssistantView.vue`
  - 删除 `grid 400px 1fr` 与左侧 `border-right`；`assistant-page` 改为 `position:relative; overflow:hidden`。
  - 地图 `.map-col` 绝对铺满，`loadAmap(..., { controls:false })`；新增右下 `MapActionButton` 放大/缩小。
  - 聊天 `.chat-col` 改为左上浮层：`top:80 / left:16 / bottom:16 / width:400`，18px 圆角、`--ui-shadow-2`、z-index 20；769–1099 为 380px。
  - 消息：用户仍为 accent 实底气泡；AI 消息去掉灰色气泡，改为「sparkles + AI 助手」小标识 + 全宽自然正文；只有草稿是 `plan-card`。
  - 草稿卡：去渐变/去边框，白底 `--ui-shadow-1`、18px 圆角；时间线 accent 圆点 + 1px 发丝线；`plan-people` 去虚线；编辑态每站改为 `surface-2` 横条，时间输入改为 v2 样式。
  - 路由结果（`AmapRouteLinks`）改为发丝线分隔的扁平列表，不再是一张白色卡片。
  - 快捷回复、地理芯片、会话/参考地图/发送按钮统一 v2 样式；保留 focus-visible。
  - 地理浮窗：z-index 收进地图栈（地图 z 0、聊天 z 20、弹窗 200）；`updateGeoPopupPos` 以聊天面板右缘 + 8px 作为左边界，锚点在聊天下方时向右钳制。
  - 地图加载失败改为居中白色异常卡；聊天、会话、参考地图、发送不受影响。
  - 活动预览弹窗增加 `ui-dialog` 皮肤，宽度 `min(380px, 94vw)`。
- 未改：流式、会话切换、参考地图选择、工具调用、草稿状态机、保存/修订、深链、地图 marker/route 控制器。
