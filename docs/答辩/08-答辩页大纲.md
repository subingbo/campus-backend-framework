# 答辩页大纲（12–15 页）

1. **封面**：项目名 + 一句话“把群里一句话变成可执行活动”。
2. **问题**：校园协作里地图、日程、活动、聊天四套系统割裂；AI 只会聊天，不会判可行。
3. **方案总览**：共享地图 + 群体忙闲 + AI 规划 + 消息中心 + Trace 五块。
4. **系统架构**：`diagrams/01-system-architecture.svg`；HTTP/SSE/WS、MySQL/Redis、qwen-plus、高德。
5. **群体空间记忆**：Map A 地点/备注/评论；Agent 读共建地图，不是临时 prompt。
6. **隐私边界**：FREE_BUSY、UNKNOWN/TENTATIVE、公开摘要白名单、群 AI 输出过滤。
7. **时空联合规划**：`diagrams/05-spatiotemporal-solver.svg`；LLM 编排 vs Java 判可行。
8. **草稿到活动**：PlanValidator、行锁、版本 409、幂等、二次校验。
9. **消息中心可靠性**：`diagrams/08-message-center-reliability.svg`；持久收件箱 + 去重 + afterCommit。
10. **公开地图回放**：只画公开站点/相邻路线；私有 A/B/C 不压缩成 A→C。
11. **Trace 证据**：`diagrams/10-trace-pipeline.svg`；脱敏、p50/p95、JSONL。
12. **量化结果**：168/168、46/46、13/13、p50 26s、Token 469k、对照实验（注明 N=3）。
13. **创新点总结**：5 条；与“AI 聊天+地图”的差异表。
14. **已知限制与路线图**：地点/活动 ACL、多实例、持久化已读；下一轮计划。
15. **Q&A 备用页**：失败模式（LLM/高德/队列）、数据隐私、成本口径。

每页只放 1 个结论 + 1 张图/1 个数字；详细证据放 `06-量化证据.md`。
