- 模型：qwen-plus（DashScope OpenAI 兼容）。

- 结果：
  - 草稿：`东区图书馆→南门咖啡漫步`，2 站，`FEASIBLE`；
  - `AGENT_GEO`：3 条；
  - 保存：`activityId=32`，活动可读、2 站；
  - Trace：`qwen-plus`，6 次工具调用，55 条事件。
- 另一次 15:00–17:00 草稿因与既有活动冲突返回 409，属于正确的业务拦截；换到非冲突时段后通过。
- 真实 LLM 等待时间约 30–150 秒；脚本超时上限 240 秒。
